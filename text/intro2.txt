// INTRO2 - FIRST DRAFT: OUTLINE (guide stage 1)
// Like intro.txt: assigns roles A/B/C, gives the player early choices,
// ends on landfall and queues [event firstday 0].
// Difference from intro.txt: storm and shipwreck arrival, and a larger
// boat - a refugee boat, not a rowboat.

// When: The evening of the final day of the voyage. It is getting dark and a
// storm has been building all evening. Days ago the sail was destroyed, and
// since then everyone has been taking turns at the oars. Everyone is tired.

// Why: You and your friends are among a larger group of refugees who fled the
// Dragon Emperor by sea - families, children, old people, all gambling on the
// uncharted lands across the water. The boat is crowded and carrying
// everything everyone owns. The intro must establish the peril, the
// community, and the cost of arriving.

// What: In the dark, the storm drives the boat onto a reef. The hull tears
// open and the boat grinds over the rocks toward the unknown shore. Everyone
// scrambles through the surf and up the beach in the storm-lit evening. All
// survive, but exhausted, and much is lost in the water.

// How: S1 is the first thing the player reads - it must SET THE SCENE: dark
// evening, tired rowers, a crowded refugee boat with families, building
// storm, the sail destroyed days ago. The grounding is narration, not a
// choice. First choice: who do you grab and hold onto in the waves when the
// boat breaks open? Leads to a short personal moment. Second choice: one
// thing you can still reach before the wreck settles - what do you take?

// But: The tension is loss and uncertainty. You can only save one item, and
// you do not know what these lands hold: danger, people, or nothing at all.
// The choice must feel like a real gamble. But the boat is NOT completely
// gone - it is wrecked on the reef, battered but still there. Much later in
// the game this leads to a choice: salvage what remains of the boat, or
// attempt to repair it.

// Who: A (proud, determined, a born leader), B (strong, calm, close to
// nature), C (clever, curious, weaker but quick-witted). Same traits as
// intro.txt: *A: divinity, -magic  /  *B: life  /  *C: -life, magic
// Also present: the other refugees - families with children, the old, the
// tired. They are the community you arrive with and will matter later.
// The chosen companion talks to you while you catch your breath in the surf.

// Finally: You stand dripping on an unknown beach in the dark, everything
// lost except the one thing you saved, surrounded by tired survivors, with
// the wreck of the boat groaning on the reef behind you. First day begins:
// [event firstday 0].

// SECTION SKETCH (guide stage 2 will formalize):

// S2-4 - Short personal moment with chosen companion in the surf:
//      A: refuses to let go of you, drags you both up (determined leader)
