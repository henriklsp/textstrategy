// INTRO2 - SECOND DRAFT: STRUCTURE (guide stage 2), revised
// Opening mood: grim. The last remaining boat, damaged and overcrowded,
// everyone tired, little fresh water left except rain water, no land in
// sight, no way back. Some are still hopeful and determined. Nothing happens
// except rowing and the sun setting.
// Structure: starts at §1, then §10. Each companion is introduced through
// dialog as their turn at the oars ends and they huddle together to talk.
// The early choices are WHAT TO SAY, not who to sit with - the player learns
// who A, B and C are before any choice about them matters.
// Tension builds gradually towards the crash on the reef, which nobody saw
// coming. Skeleton text only - basic text and effects come in later stages.
// Ends with night; the first day continues in the firstday event.

// STAGE 2 NOTES:
// - Starts at §1 (scene-set), then §10 (A), §20 (B), §30 (C).
// - Every companion gets: an intro section (through their own words) with a
//   what-do-you-say choice of three options (hope / plan / listen), and each
//   option has its own short reaction section before moving on.
// - No prerequisites yet: the player starts with no variables.
// - No alternative ending: the voyage always ends on the reef.
// - The chosen item (food/silver/axe) sets variables in a later stage, and
//   §70 queues the first day.
// - Loop check: every section has exactly one choice (§1 and §70 by design:
//   §1 only continues, §70 ends); §11-§13 funnel to §20, §21-§23 to §30,
//   §31-§33 to §40, §51-§53 to §60, §61-§63 to §70; no dead ends, no repeats.
// - Dramatic arc: grim quiet and introductions (§1-§33) - rising tension
//   (§40) - climax and companion decision (§50-§53) - falling action and
//   main decision (§60-§63) - night (§70).
