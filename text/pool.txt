//   filler:      → events listed under it are fillers: considered only when no
//                  watched event can fire

// header conditions are met); it leaves the pool (fires once per registration).
// Scheduled events (not in this file) only fire when an [event x n] effect queues them.
// Events can also be registered from code with GameLoop.registerPoolEvent(name, tier?).
